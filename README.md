# 🏃 Endless Runner Game — Unity

> A simple endless runner game developed with Unity and C#, featuring continuous gameplay, coin collection, power-ups, dynamic ground generation, and obstacles.

![Unity](https://img.shields.io/badge/Unity-Game%20Development-black)
![CSharp](https://img.shields.io/badge/C%23-Scripting-purple)

---

## 📌 Overview

This project explores fundamental game-development concepts using Unity and C#.

The player moves through an endless environment while avoiding obstacles and collecting coins to increase the score.

The project focuses on implementing basic gameplay mechanics and experimenting with Unity's scene, scripting, and asset systems.

---

## 🎮 Features

- 🏃 Endless runner gameplay
- 🪙 Coin collection
- 🧲 Magnet power-up
- 🌍 Dynamically generated ground
- 🚧 Obstacles
- 📈 Score-based gameplay
- 🎮 Player interaction and movement

---

## 🎯 Gameplay Objective

The objective is to:

1. Continue running through the environment.
2. Avoid obstacles.
3. Collect coins.
4. Use available power-ups.
5. Achieve a higher score.

## 🚀 Getting Started

### Prerequisites

- Unity
- C# / Unity development environment

### Open the Project

1. Clone the repository.
2. Open the project using Unity Hub.
3. Allow Unity to import the project assets and packages.
4. Open the available game scene.
5. Run the project from the Unity editor.

---

## 🧩 Gameplay Systems

### Coin Collection

Coins are placed throughout the environment and contribute to the player's score.

### Magnet Power-Up

The magnet power-up attracts nearby coins toward the player.

### Endless Ground

The game generates ground sections to create an endless running environment.

### Obstacles

Obstacles are positioned along the running path and require the player to avoid collisions.
