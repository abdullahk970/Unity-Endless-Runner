# 🏃 Endless Runner Game (Unity)

## 📌 Description

This is a simple **Endless Runner game** developed using the Unity game engine. The player runs continuously on an infinite track while avoiding obstacles and collecting coins to achieve a high score.

---

## 🎮 Features

* **Imported Player Model**
  Player character imported from Unity Asset Store.

* **Coin Collection System**
  Coins are placed along the path. The player can collect them to increase score.

* **Magnet Power-Up**
  A magnet feature is implemented that automatically attracts nearby coins towards the player for a limited time.

* **Endless Ground System**
  The ground is generated dynamically, creating an infinite running environment.

* **Obstacles**
  Different obstacles are placed on the path to make the game challenging. The player must avoid them to survive.

---

## 🛠️ Technologies Used

* Unity (Game Engine)
* C# (Scripting)

---

## 🎯 Objective

Survive as long as possible, avoid obstacles, and collect maximum coins to achieve the highest score.
